# 成片与发布包验收

只在 `rendered` 阶段读取。

## 机器检查

运行：

```powershell
python "<本 Skill 目录>\scripts\verify_package.py" "<episode.json绝对路径>"
```

脚本检查最终视频、音轨、尺寸、封面、UTF-8文本、CTA、官方来源、费用核实和发布字段。失败时只处理报告中的失败字段，不重新制作无关部分。

## 视觉检查

机器检查通过后，从最终视频提取并查看：

- 约 1 秒的开头结果；
- 每个主要场景的英雄帧；
- 字幕最密集的位置；
- 费用或限制说明；
- CTA和最后一帧；
- 两种封面。

确认：

- 0–5 秒有具体结果，不是长介绍；
- 画面按音频时间轴正确切换；
- 真实操作清晰、没有错误裁切；
- 字幕在中央安全区，没有被界面或抖音控件遮挡；
- 中文无乱码，专有名词和项目名称正确；
- API Key、账号、余额、私人路径和通知均已隐藏；
- CTA口播和字幕完整同步；
- 竖封面与 4:3 横封面均可读。

## 事实复核

发布前只刷新容易变化的事实：项目版本、维护状态、下载入口和费用。不要重新浏览已经锁定的全部研究资料。

全部通过后，用 `scripts/update_episode.py` 把 `qa.passed=true`、报告路径和 `stage=qa_passed` 写入状态。然后运行 `scripts/build_publish_payload.py`。浏览器阶段不得直接从聊天内容拼装发布字段。
