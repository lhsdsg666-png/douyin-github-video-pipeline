# GitHub 高价值项目短视频默认视觉规范

## 视觉方向

- 关键词：清晰、可信、开发者工具、结果优先、克制的科技感。
- 使用真实项目界面、官方网页和用户实际操作素材，不伪造成功结果。
- 左上角与顶部 180px 保持干净；关键标题、字幕和操作结果位于中央安全区。
- 开头 0–3 秒先展示痛点或结果，再介绍项目名称。

## 色彩

- 背景：`#081522`
- 深层背景：`#040A10`
- 主文字：`#F2F6F8`
- 次级文字：`#A8B8C8`
- 强调色：优先取项目官方品牌色；无法可靠取得时使用 `#8FB7E8`
- 风险与费用提示：`#F0C77A`

## 字体与安全区

- 中文标题和字幕：`Microsoft YaHei UI`，粗体。
- 技术命令：`Cascadia Mono`。
- 画布：`1080x1920`。
- 重要内容区域：横向距离边缘至少 72px；顶部重要内容不早于 200px；字幕不得贴近底部平台控件区。
- 标题 76–104px；字幕 52–62px；技术标签不小于 30px。

## 动效

- 多场景必须有明确转场和各自的入口动画。
- 先完成静态英雄帧布局，再添加动画。
- 画面每 1–3 秒应出现有意义的视觉变化，但不得为变化而变化。
- 最后一场包含自然关注引导，并与口播字幕同步。

## 不要这样做

- 不在顶部或左上角放核心信息。
- 不用未经核实的产品界面、数据或成功状态。
- 不暴露凭据、账号、余额、私有路径和会话。
- 不用密集小字代替可读的关键结论。
- 不把横封面做成 16:9；必须交付 `1440x1080` 的 4:3 版本。
